# Poker Programming Experiments

A collection of JavaScript experiments exploring poker-hand evaluation, card representation, and interactive browser interfaces.

The project includes code for representing a standard 52-card deck, identifying poker hands, and comparing hand rankings.

These programs were developed as personal programming exercises in 2020.

## Interactive Demonstrations

- [Poker Hand Evaluator](cards.html)
- [Card Selection Interface](pear.html)
- [Three-Card Selector](plum.html)

## Implementation

Written in JavaScript, HTML, and CSS, with Chart.js used for graphical output.

The code is experimental and has not been developed into a complete poker application.
